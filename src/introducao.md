# Guia Prático do Flutter

Bem-vindo ao **Guia Prático do Flutter**! Este livro foi pensado para levar você, passo a passo, dos conceitos fundamentais do Flutter até técnicas usadas em aplicativos reais.

## 🎯 Para quem é este livro

- Iniciantes que querem criar o primeiro app com Flutter
- Desenvolvedores de outras tecnologias migrando para Flutter
- Estudantes que buscam material prático, em português, com código comentado

## 📋 Pré-requisitos

- Noções básicas de programação (variáveis, funções, classes)
- Flutter SDK instalado (veja o [Apêndice A](./appendix_a.md))
- Um editor de código, como VS Code ou Android Studio

## 🗺 Como o livro está organizado

| Parte | Capítulos | O que você aprende |
|-------|-----------|--------------------|
| Fundamentos | 1 a 3 | Widgets, layouts, formulários e navegação entre telas |
| Gerenciamento de Estado | 4 e 5 | Provider e BLoC |
| Dados e Qualidade | 6 a 8 | APIs, testes, SQLite e armazenamento local |
| Indo para Produção | 9 e 10 | Publicação, splash screen, recursos avançados e Firebase |
| Apêndices | A a F | Ambiente, dicas, recursos, glossário, projetos e Dart essencial |

> 💡 Nunca programou em Dart? Comece pelo [Apêndice F - Dart Essencial](./appendix_f.md).

## 🎓 Como estudar

1. Leia o capítulo com o editor aberto ao lado.
2. Digite os exemplos em vez de copiar e colar: isso fixa a sintaxe.
3. Rode o app (`flutter run`) e use o **Hot Reload** para experimentar variações.
4. Ao final de cada capítulo, tente adaptar o exemplo para uma ideia sua.

> 💡 Use a barra lateral (ou as setas ← →) para navegar entre os capítulos e o ícone de lupa para buscar no livro.

Bons estudos! 🚀
